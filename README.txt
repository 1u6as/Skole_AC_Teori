AC THEORY – VERSION 3

Indhold:
- Formeloversigt og formelhjælper på dansk.
- Vælg formelniveau: Kun grundlæggende eller Grundlæggende + avanceret.
- Avancerede emner omfatter sinus/RMS, komplekse impedanser og fasorer, resonans og Q-faktor, trefaset AC, transformatorer, filtre samt effektkompensering og harmonisk forvrængning.
- Formelfinderen kan følge flere trin: Når en formel kan finde en ny størrelse, kan den størrelse bruges som kendt i næste trin. Appen beregner ikke talværdier.
- Søgning og filtrering efter emne.
- PWA, så appen kan installeres på Android og computer via HTTPS.

INSTALLATION / OPDATERING PÅ GITHUB PAGES
1. Pak ZIP-filen ud.
2. Upload index.html, manifest.json, sw.js og README.txt til roden af dit repository.
3. Erstat de gamle filer og commit ændringerne til den branch, GitHub Pages udgiver fra (typisk main / root).
4. Vent på GitHub Pages-deploy.
5. Genindlæs siden. Hvis en gammel version stadig vises, luk appen helt og åbn den igen. Service Worker-cache er opdateret til v3.

VIGTIGT
- Appen er et opslagsværktøj og regner ikke automatisk.
- Trefaseformlerne forudsætter balanceret belastning, medmindre andet er angivet.
- RMS/spidsværdi-formlerne gælder sinusformede signaler.
- Transformatorformlerne er idealiserede og ser bort fra tab.
- Filterformlerne gælder de angivne standardkoblinger.
- Formeloversigten er omfattende, men kan ikke indeholde enhver specialformel for alle mulige kredsløb og standarder. Kontrollér altid antagelser, enheder og fortegn i opgaven.
